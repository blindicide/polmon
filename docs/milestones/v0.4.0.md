# Milestone v0.4.0 — Russian UI and interface quality pass (Phase IV)

VERSION: v0.4.0
STATUS: PASS

IMPLEMENTED: (1) **Internationalization.** A Qt-free runtime (`polmon.client.i18n`: `tr`, CLDR
plurals, lazy `Msg` values, weak widget bindings re-rendered on a switch) and two catalogs
(`locales/ru.py`, `locales/en.py`, 907 keys each, identical keys and placeholders). Russian is
the default of the packaged client; English is selectable at run time (*Вид → Язык*,
Ctrl+Shift+U, `--language`, `POLMON_LANGUAGE`) without a restart: connection, documents, tables,
selection, a running operation and the current page are kept. Qt's own strings follow through
`qtbase_ru.qm`, which the bundles now ship; the self-test checks both languages and the Qt
translation. Unit symbols, identifiers, JSON keys, CLI flags and protocol names are not
translated. (2) **Backend text by message code — approach (a)** (ARCHITECTURE.md, CHANGELOG.md):
every backend error document carries `message_code` and `params` beside the unchanged English
`message`, as do validation items, experiment errors, benchmark jobs and YAML errors (line,
column, `problem_code`); an AST test fails on an uncoded raise site. The client renders
`backend.<message_code>` — the L0-only refusal, admission limits, validation problems and
connection failures appear in Russian, never as raw backend text or a traceback. (3)
**Gates.** `scripts/i18n-lint.py` fails on a user-visible literal in client code;
`scripts/i18n-completeness.py` fails on missing or unused keys, placeholder or plural-form
mismatches, empty values, English left in Russian, Cyrillic in English, glossary variants, and
any backend message code without a translation. Both run in CI on Linux and Windows; the GUI
suite runs in Russian and again in English, and a screen walk asserts no English prose on any
Russian screen and no Cyrillic on any English one across a runtime switch. Tests assert on
object names, catalog keys, `Problem.key` and message codes. (4) **Design pass.** Light and dark
token sets (one teal accent on slate neutrals, semantic status colours with soft surfaces),
4-px spacing, a type scale, 28-px controls, a rewritten stylesheet; dark sidebar navigation and
a slim connection header; cards, aligned key/value grids and metric tiles with sparklines;
tables sized from their cells with monospaced identifiers, right-aligned numbers and status
glyphs; empty/loading/error states everywhere; a status-bar busy indicator; one primary action
per screen; destructive actions (destroy, reset, disconnecting from the Local backend) styled
as such and confirmed; accessible names for every input; tab order sidebar → header → page →
log. (5) **docs/UI-GUIDE.md**: tokens, scales, components, glossary (English ↔ Russian ↔
concept, with rejected variants enforced by the gate), usability floor, shortcuts, screenshot
inventory.
