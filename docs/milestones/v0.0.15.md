# Milestone v0.0.15

VERSION: v0.0.15
STATUS: PASS

IMPLEMENTED: Release candidate with feature freeze. Audits performed: documentation (all ten
mandatory root documents plus `docs/*` read against the implementation; corrected BUILD-WINDOWS,
CONTRIBUTING, SECURITY, API, TOPOLOGY, REPORTING-RECOVERY), regression (rootless, privileged,
performance), resources, security review, Windows packaging, clean installation, cleanup and
interrupted-execution recovery, repository hygiene. Corrections made for failures found:
1. Security: path-like `experiment_id` values (`../escape`) reached telemetry and returned HTTP 500
   (traversal was blocked only incidentally by the telemetry id check). Identifiers are now
   pattern-validated at the API boundary (HTTP 422, nothing written) and independently in report
   write/read.
2. Recovery: SIGTERM/SIGINT of `polmon-backend` left live namespaces, bridge, veths, and a running
   lab service. Proven with a negative control on the old code, which leaked two namespaces, a
   bridge, two veths, and an HTTP service process (then removed by `lab-cleanup.sh --apply`).
   Graceful shutdown now resets every deployment and logs `shutdown_cleanup`.
3. Recovery: a timed-out benchmark worker was SIGKILLed before its teardown. It now receives SIGTERM
   and a 20 s grace period; a timed-out privileged target run left no resources. `lab-cleanup.sh`
   now also stops processes running inside leftover platform namespaces.
4. Security (spec §7): lab subnets were unrestricted; only RFC 1918 and RFC 2544 ranges are accepted.
5. MVP gate: experiments were refused on hybrid deployments ("not yet supported"), which blocks the
   v0.1.0 demonstration of one experiment on a 50 L0 + 2 L1 network. Added
   `HybridScenarioExecutor` routing L0→L0 (engine), L0→L1 (TAP), L1→L1 (kernel) and reporting L1→L0
   and L0-sourced TCP as `unsupported` (no emulation); TAP and engine frames go to the capture. No
   architectural change: it composes the existing executors and backend methods.
6. Logs: the Windows runner printed `NOT RUN � environment` (cp1252 console mojibake); the Windows
   job now runs with `PYTHONUTF8=1` and prints `NOT RUN — environment` correctly.
Hygiene: removed the obsolete v0.0.2 privileged placeholder test (misleading skip in every
privileged run); stopped tracking `INSTRUCTION.md` (committed in bed7322 by the previous session;
history not rewritten, file kept on disk) and ignored the operator files; UTF-8 scan of all tracked
files found no invalid UTF-8, BOMs, or mojibake patterns (CSV results use RFC 4180 CRLF by design).
